# 🚀 Dolai Rajesh Kumar — DevOps & Multi-Cloud Portfolio

A modern, high-performance, dark-mode developer portfolio tailored for **Dolai Rajesh Kumar** (DevOps Engineer & Multi-Cloud Specialist across AWS, Microsoft Azure, and GCP). Built with pure HTML5, CSS3, and modern JavaScript with zero external build dependencies.

---

## 🌟 Key Highlights & Features

1. **DevOps Aesthetic & Dark/Light Themes:**
   - Tech-forward dark theme with terminal glow, subtle background grid, and one-click light theme toggle.
2. **Multi-Cloud Expertise (AWS • Azure • GCP):**
   - Full-stack multi-cloud architecture covering compute, virtual networks, managed Kubernetes (EKS, AKS, GKE), and cloud storage.
3. **Interactive Linux Terminal Console:**
   - Recruiter-engaging CLI emulator with custom commands: `help`, `whoami`, `skills`, `experience`, `projects`, `pipeline --run`, `cat resume.txt`, `pillars`, `contact`, `uptime`.
4. **Visual DevSecOps Pipeline Simulator:**
   - Interactive 6-stage continuous delivery pipeline visualizer (Source → Build → DevSecOps Scan → Multi-Cloud Container Registry → Kubernetes Blue/Green → SRE Telemetry) with live execution animations.
5. **Categorized Skills Matrix:**
   - Interactive filtering by domain: *AWS*, *Microsoft Azure*, *Google Cloud (GCP)*, *Containers & K8s*, *CI/CD & GitOps*, *IaC & Config*, and *SRE & DevSecOps*.
6. **Career History & Featured Projects:**
   - Production experience at **CW Suite India Pvt Ltd** (Retail ERP/POS SaaS) and deep dives into enterprise CI/CD and multi-cloud microservices architectures.
7. **Infrastructure as Code (IaC) Included:**
   - Includes `deploy-aws.tf` for deploying this portfolio directly to AWS S3 with Terraform.

## ⚡ How to Preview Locally

### Option 1: Direct File Open (Instant)
Simply double click `index.html` or open it in your browser (Google Chrome, Edge, Brave, Firefox).

In PowerShell:
```powershell
Start-Process "C:\Users\admin\devops-portfolio\index.html"
```

### Option 2: Using Node.js
```powershell
cd C:\Users\admin\devops-portfolio
npx serve .
```
Then open `http://localhost:3000` in your browser.
